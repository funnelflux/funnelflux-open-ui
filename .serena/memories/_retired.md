# Serena memories retired (2026-06-05)

This project's Serena memories were removed because they duplicated — and had begun
to drift from — the canonical, actively-curated guidance. **Do not recreate them.**

Canonical sources of truth (read these instead):

- **Project overview, build/test/lint, commands, conventions, verification:** root
  `AGENTS.md` / `CLAUDE.md` (and any nested `AGENTS.md`).
- **Operational gotchas / invariants / failure modes (the "why"):** the repo's
  hot-memory / `docs/` context notes where present.
- **Self-verifying code-location facts:** h5i claims (`h5i_claims_add`) — they
  auto-invalidate when the cited file changes.

Serena's symbol/LSP tools (find_symbol, references, etc.) remain useful and are
unaffected — only the redundant memory notes were retired.
